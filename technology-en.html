A technology overview — not a product sales page

Reading interactions,
translating them into color.

Detex Lab is developing a PCDA-based paper sensor platform that combines a responsive material system with molecular recognition elements designed for selected target substances.

  • PCDA-based
  • Modular sensor architecture
  • Validation prototype

This page explains the conceptual principle of the technology. It does not include performance figures, interpretation standards, or detailed usage instructions.

FROM INTERACTION TO COLOR CHANGE

From interaction
to color change

The response Detex is researching can be described as three conceptual steps. Each step is a design concept and does not represent per-substance reaction conditions or interpretation standards.

  1. STEP1

    Molecular interaction

    A recognition element designed for a selected target participates in a chemical interaction.

  2. STEP2

    Change in the responsive structure

    The interaction can alter the organization of the PCDA-based responsive structure.

  3. STEP3

    Visible color-change signal

    The structural change can appear as a visible color-change signal.

Conceptual illustration · It shows that a color change occurs; the final colors and reaction conditions are not confirmed. It cannot be used as an interpretation standard for individual substances.

MODULAR SENSOR ARCHITECTURE

A modular approach built
on a shared responsive platform

The platform is designed around a shared responsive structure while allowing the molecular recognition element to be adapted for a selected target. This architecture is being studied as a foundation for future sensor applications.

Shared responsive base PCDA-based responsive platform

The responsive structure kept identical across configurations.

+
Target-specific element Target-specific recognition element

The part whose design is adapted for a selected target.

↓
Per-target configuration Sensor configuration for a selected target

The shared base and the target-specific element combine into a single sensor configuration.

Conceptual illustration · The actual implementation may change during development.

Long-term research direction Exploring sensor applications beyond drink safety, including food and environmental contexts. For now, our focus is drug detection in beverages.

WHAT THE SIGNAL MEANS

What the color-change signal means

!
ESSENTIAL SAFETY NOTICE

No color change does not guarantee that a drink is safe. This product is not a substitute for legal, forensic, or medical confirmation.

A color change is a screening signal

A color change is a screening signal indicating the possible presence of a target substance. The signal alone cannot provide legal, forensic, or medical confirmation of substance identity or concentration.

What this page does not cover

Detailed usage and per-substance interpretation standards will follow once product specifications are finalized. No performance figures are presented on this page.

Current development stage

Detex is a prototype for validation and is not yet commercially available. Independent validation results will be published separately once available.
